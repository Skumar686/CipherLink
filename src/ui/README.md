# CipherLink — Obsidian Edition

This is a visual refresh of the six supplied React components. Existing props, handlers,
state, networking calls, and encryption-related logic are intentionally preserved.

## Apply it
1. Back up your current components.
2. Replace the matching component files with the files in this folder.
3. Import `obsidian-theme.css` from your app's global stylesheet/entry point.
   For example: `import './obsidian-theme.css';`
4. Run the app and check the modal and call layouts at desktop and mobile widths.

The font stylesheet uses Google Fonts, so the custom fonts require an internet connection.
The rest of the styling falls back to system sans-serif/monospace fonts.
